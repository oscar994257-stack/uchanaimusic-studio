# 官網更新摘要｜2026-10-29

## 最新確認：可切換完整電腦版

依使用者更正，移除「橫放手機」提示及自動橫向分欄，改成像一般網站的「電腦版／手機版」選擇。

- 手機導覽列最前方有「電腦版」按鈕；切換後，同一導覽列有「手機版」可返回。
- 電腦版網址為 ?view=desktop，使用 1280px 整頁寬度，手機瀏覽器可將完整頁面縮小呈現，再由使用者雙指放大、拖曳查看。
- 手機版網址為 ?view=mobile；未指定時也使用手機自適應版面。重新整理會保留網址中的模式。
- 電腦版會明確維持導覽列、首頁圖文、影片／廣告、五張作品縮圖、工具、商店及頁尾的電腦排版，不會被窄螢幕的手機斷點改成單欄。
- 沒有設定 maximum-scale、minimum-scale 或禁止使用者縮放。沒有旋轉／全螢幕要求。
- 所有模式切換都只影響公開首頁，不影響 /studio 後台。
- 為依網址輸出正確 viewport，首頁改成動態頁；Sanity 內容仍保留 60 秒資料快取。

驗證：型別檢查；手機版→電腦版→手機版的實際連結操作；390px 視窗下電腦版保持 1280px 並確認各主要區塊左右分欄；手機版恢復 device-width、單欄且無橫向溢出。伺服器 HTML 已確認電腦版 viewport 為 width=1280, user-scalable=yes，手機版為 width=device-width, initial-scale=1, user-scalable=yes。瀏覽器工具未提供實體手機觸控模擬，因此未宣稱完成實體手機雙指操作驗證。

## 免費廣告合作規則

目前開放免費廣告合作版位，歡迎品牌與創作者洽詢。若未來調整為收費制，將另行公告，並於刊登或續刊前確認費用；已確認的免費刊登期間不追溯收費。

- 官網作品區新增固定規則說明；輪播預留卡標示免費廣告合作。
- 合作條款五種語言同步更新，版本 2026-10-29-draft-2。
- 原有每次最長一個月、同一合作最長三個月的刊期限制保留。
- 目前刊登不用付款；未來付費刊登須先確認並同意，不自動扣款。
- 費用退款及按廣告費計算的提前終止補償，僅適用於另行書面確認的付費刊登。
- 後台啟用提示改為確認素材與刊登安排，不再要求付款。
- 此次只更新規則與介面，沒有對外寄信、收款或啟用廣告。
