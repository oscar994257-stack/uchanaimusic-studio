# 官網更新摘要｜2026-10-30

- 跑馬燈改用無襯線字體、提高對比及字重，電腦版 20px、手機版 16px；減少字距，移動週期由 32 秒放慢至 56 秒。修正移動範圍，完整文字離開後才重新開始。
- 合作訊息標籤支援繁中、簡中、英文、日文與韓文。新增獨立暫停／繼續按鈕，單則廣告也能暫停跑馬燈；滑鼠停留與鍵盤聚焦時暫停。偏好減少動態者改為靜態換行顯示。
- 廣告標頭清楚顯示目前版位，例如「版位 1 / 4 · 示範」，不再以有效廣告筆數顯示容易誤解的 1 / 1。
- 固定顯示四個版位格：已刊登者可選擇，2–4 的空位以虛線與「空位」標示，點選開啟聯絡信件，主旨帶入版位編號；1 號未刊登時仍標示示範預留。
- 顯示「已使用 N / 4」及可洽詢合作空位數。示範位 1 不納入對外合作空位數；目前空位是依有效刊登資料判斷，實際刊期仍需確認。
- 空位不加入自動輪播。既有圖片每 5 秒切換、影片手動播放與結束後 10 秒切換規則保留；未新增或改寫雲端廣告資料，也未建立測試廣告。
- 原有字數不含空格、五語素材清單及 YouTube 宣傳標示說明保留。
- 後續依使用者更正，跑馬燈固定改為工作室免費廣告招募文案，不再讀取個別廣告 caption；廣告每五秒換則時不會改變跑馬燈文字。文案有完整五語版本，移除原廣告文案的 100 字截取，避免英文等語言被截斷。
- 後台舊 caption 欄位停用並隱藏、移除草稿預覽及公開廣告查詢中的 caption；既有雲端原文仍保留，沒有刪除資料。大字、慢速、獨立暫停及四個版位顯示不變。
- 廣告影片操作提示與下方輪播狀態提示，由 10px 放大為 14px，加深文字對比並提高字重；多語或手機窄螢幕可自然換行，不裁切內容。

驗證：npm run test:ads 與 npm run build 完整通過。本機正式建置預覽確認電腦版 20px／56 秒、手機版 16px，跑馬燈獨立暫停及繼續正常；固定四格中一格刊登、三格空位，使用／空位統計正確。已實際切換五種語言；390px 手機視窗的版位控制不溢出，主控台無錯誤。未點選寄信或修改任何雲端廣告資料。
